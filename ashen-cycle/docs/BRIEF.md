# ASHEN CYCLE (잿빛 순환) — 디자인 브리프

> 이 문서는 방향과 제약이다. 모듈별 API · 수치 · 상태 형태는 `docs/CONTRACT.md`가 정한다.
> 요청 원문(Jay, 2026-10-02): "3D Action 게임을 제작해줘. 3인칭으로 진행되고 엘든링이나 다크소울3같은 느낌의 보스전과 마을에서의 정비 두 구간을 계속해서 오가며 빠르게 캐릭터를 성장시키고 또다시 보스에게 도전할 수 있는 게임을 제작해줘. Three.js로 제작해줘."
> 규칙과 기술 기본값은 리포 루트 `CLAUDE.md`다. 이 브리프는 그 규칙이 생기기 전에 쓴 것이라 §8에 기술 제약을 전부 적어 두었다.

## 1. 한 줄

3인칭 소울라이크 보스 러시. **마을(정비) ↔ 보스전** 두 구간을 짧게 오가며, 죽어도 성장하고, 성장해서 곧바로 다시 도전한다.

## 2. 핵심 루프 (가장 중요)

```
마을(화톳불 · 대장장이 · 상인 · 안개문)  ──안개문──▶  보스전
        ▲                                              │
        └──── 승리(큰 보상 · 다음 보스 해금) / 사망(준 피해만큼 보상) ◀┘
```

- **죽어도 잃지 않는다.** 사망 시 보스에게 준 피해 비율만큼 재화(잔불)를 받는다. 재화 분실 · 회수 없음.
- **한 번 다녀오면 반드시 뭔가 살 수 있다.** 첫 도전에서 보스 HP 30%를 깎고 죽어도 레벨업 2~3회가 가능해야 한다.
- **전환이 빠르다.** 사망 → 결과 패널(획득 잔불 · 준 피해 %) → `[즉시 재도전]` / `[마을로]`. 전환 페이드 1초 이내. 로딩 화면 없음.
- 보스 1은 3~6회 도전 안에 잡히는 것이 목표. 보스 한 판은 60~150초.
- 보스 3종을 모두 잡으면 **순환 +1**(보스 HP · 피해 · 보상 배율 상승, 2페이즈 패턴 강화)로 끝없이 이어진다. 해금된 보스는 안개문에서 골라 재도전할 수 있다(재도전 보상은 감쇠).

## 3. 전투 — 소울라이크의 감각

플레이어:
- 3인칭 궤도 카메라(마우스) · **록온**(보스 고정, 록온 중에는 보스를 바라보며 스트레이프)
- 스태미나: 공격 · 구르기 · 달리기 · 가드에 소모, 행동을 멈추면 회복. 0이면 행동 불가(가드 붕괴).
- 약공격 연속기(무기별 3~4타), 강공격(홀드 차지), 대시 공격, 구르기 직후 공격
- **구르기**: 무적 프레임(i-frame) 있음. 방향 입력 없으면 백스텝.
- **가드**: 피해 경감 + 스태미나 소모. 가드 시작 직후 짧은 창에 맞으면 **패링**(피해 0 · 보스 체간 대량 누적).
- **체간(자세)**: 보스에게 누적 → 가득 차면 그로기(다운) → 정면에서 **처형 공격**(큰 피해).
- 회복 플라스크(충전식, 마을에서 보충). 사용 중에는 느리게 걷고 취소 불가.
- 입력 버퍼(선입력), 공격 중 방향 고정, 회복 프레임에서 구르기 캔슬 창 — 조작이 "씹히지" 않아야 한다.
- 히트스톱 · 화면 흔들림 · 스파크 · 무기 궤적으로 타격감을 준다.

보스(3종, 각 2페이즈):
- 모든 공격은 **예고(windup) → 판정(active) → 후딜(recovery)** 세 구간. 예고는 눈으로 읽을 수 있어야 하고(자세 · 발광 · 바닥 표식), 후딜은 반격할 수 있을 만큼 길다.
- 예고 중에는 플레이어를 추적하다가 판정 직전에 방향을 고정한다(구르기로 피할 수 있게).
- 지연 공격 · 연속기 · 광역(충격파 링) · 돌진 · 투사체를 섞는다.
- HP 50%에서 2페이즈 전환(포효 연출 + 신규 패턴 + 속도 상승).
- 보스 성격:
  1. **잿빛 기사 발더** — 대검을 쓰는 인간형. 정직한 휘두르기 · 찌르기 돌진 · 도약 내려찍기. 2페이즈: 불 인챈트 · 충격파 · 지연 베기. "패턴 학습의 교과서".
  2. **서리 송곳니 펜리르** — 거대 늑대(사족). 빠른 물기 · 돌진 · 꼬리 쓸기 · 도약 덮치기 · 냉기 브레스(부채꼴). 2페이즈: 얼음 가시 장판. "속도와 거리 조절".
  3. **심연의 군주 니힐** — 부유하는 마술사. 유도 구체 · 순간이동 · 광선 쓸기 · 지면 폭발 · 검 비. 2페이즈: 복합 패턴. "원거리 압박과 틈 찾기".

## 4. 성장 — 빠르고 눈에 보이게

- 재화: **잔불**(레벨업 · 강화 · 구매 공용), **보스 파편**(무기 강화 재료 — 보스에게 준 피해 구간 달성 · 격파로 획득).
- **화톳불**: 레벨업. 능력치 4종 — 생명력(HP) · 지구력(스태미나 · 회복) · 근력(피해) · 기량(체간 피해 · 치명/처형 피해). 플라스크 충전, 현재 능력치 미리보기(올리기 전/후 수치 비교).
- **대장장이**: 무기 강화(+1…+10), 무기 교체. 무기 3종 — 장검(균형) · 대검(느리고 강함 · 체간 피해 큼) · 창(빠른 찌르기 · 긴 사거리). 무기마다 연속기 타이밍 · 범위 · 소모가 다르다(데이터 주도).
- **상인**: 플라스크 충전 횟수 +, 회복량 +, **유물**(패시브. 2칸 장착 — 예: 구르기 직후 피해 증가, 패링 창 확대, 스태미나 회복 증가, 흡혈, 저체력 시 피해 증가).
- 레벨업 비용은 완만하게 오른다. 능력치 한 점의 효과가 체감돼야 한다(수치 미리보기).
- 진행 상황은 localStorage에 자동 저장(마을 진입 · 구매 · 보스전 종료 시).

## 5. 마을

- 작은 원형 광장(반경 ~18m). 중앙 화톳불, 둘레에 대장장이 · 상인 · 안개문 · 훈련용 허수아비(공격 연습, 피해 수치 확인).
- 3인칭으로 걸어 다니고 `E`로 상호작용 → HTML 패널. 부활 지점은 화톳불 옆(모든 시설이 몇 걸음 안).
- 마을에서는 공격 · 구르기가 가능하되 피해를 받지 않는다(허수아비 연습).

## 6. 조작 (키 바인딩은 데이터 표로 — 바꿀 수 있게)

## 7. 보여 주기

- 외부 에셋 0. 모델 · 텍스처 · 소리 전부 **절차 생성**(지오메트리 조합 리그 · 캔버스/셰이더 텍스처 · WebAudio 합성).
- 다크 판타지 톤: 낮은 채도, 안개, 불빛(화톳불 · 인챈트 · 마법)의 발광이 포인트. 블룸 · 그림자 · 톤매핑.
- 캐릭터는 관절 계층 리그 + **코드 애니메이션**(상태와 경과 시간에서 포즈를 계산). 공격의 예고 · 판정 · 후딜이 실루엣으로 구분돼야 한다.
- HUD(HTML/CSS): 좌상단 HP · 스태미나 바, 플라스크 수, 잔불 카운터, 하단 보스 이름 + HP 바 + 체간 바 + 누적 피해 수치, 록온 표식, 상호작용 프롬프트, `YOU DIED` / `보스 격파` 배너.
- UI 문면은 한국어. 문자열은 한 파일에 모은다.
- 소리: 휘두르기 · 타격 · 가드 · 패링 · 구르기 · 발소리 · 보스 포효 · 플라스크 · UI + 마을/보스 분위기 음(합성 드론 · 타악 펄스). 볼륨 설정.
- 메뉴: 타이틀(새 게임 · 이어하기) · 일시정지(감도 · 볼륨 · 화질 · Y반전 · 조작 안내).
- 성능: 중급 GPU 60fps. 픽셀 비율 상한 2, 화질 3단계.

## 8. 기술 제약 (확정)

1. **스택**: Vite + `three`(npm 최신) + 바닐라 JS ES 모듈. TypeScript · 프레임워크 · 물리 엔진 없음. 타입은 JSDoc `@typedef`.
2. **계층 분리** — 이것이 병렬 개발과 검증의 토대다:
   - `src/sim/` — **순수 JS 시뮬레이션**. `three` · DOM · WebAudio를 import하지 않는다. 전투는 XZ 평면 2D(원 · 부채꼴 · 링 · 선분 캡슐 판정), 높이는 표현용 값만. 고정 틱(1/60초), 시드 난수. Node에서 그대로 돈다.
   - `src/view/` — three.js 표현. sim 상태를 **읽기만** 하고 이벤트를 구독한다. sim을 바꾸지 않는다.
   - `src/ui/` — HTML/CSS HUD · 메뉴. sim 상태 읽기 + 명령 메서드 호출.
   - `src/audio/` — WebAudio. 이벤트 구독.
   - `src/app/` — 부트스트랩 · 루프 · 화면 전환 · 입력 수집 · 저장 · 디버그 API.
   - `src/data/` — 무기 · 보스 · 유물 · 능력치 곡선 · 문자열 · 키 바인딩(순수 데이터).
3. **상태의 정본은 sim**이다. view/ui/audio는 sim 상태와 이벤트 버스만 본다. 입력은 app이 매 틱 `InputFrame`(순수 객체)으로 만들어 sim에 넘긴다 — 테스트의 봇도 같은 형태를 만든다.
4. **수치는 전부 데이터**(`src/data/`)에 둔다. 로직에 박지 않는다.
5. **검증 게이트**(에이전트가 스스로 돌린다):
   - `npm run build` — Vite 빌드 오류 0.
   - `npm test` — `node --test`. 진행/경제 수식, 저장 왕복, **헤드리스 봇 대전**(봇이 각 보스와 N초 싸움: 예외 0 · NaN 0 · 양쪽 피해 발생 · 2페이즈 전환 · 사망/승리 보상 이벤트).
6. **디버그 API** `window.__ashen` — 브라우저 자동화용: 상태 조회, 보스전 바로 시작, 잔불 지급, 봇 조종 on/off, 시간 배속, 무적.
7. 충돌: 캐릭터는 XZ 원. 아레나는 원형 경계(+ 선택적 기둥 원). 마을은 원형 경계 + 시설 원/상자 콜라이더.
8. 좌표: Y-up, 단위 m, 플레이어 키 ≈ 1.8.

## 9. 범위 밖
