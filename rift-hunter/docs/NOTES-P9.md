# NOTES-P9 — app (W2)

계약의 공개 이름 · 시그니처 · 이벤트는 바꾸지 않았다. 계약이 비워 둔 해석과 남의 파일에 걸린 것만 적는다.

## 계약 해석(내 파일 안에서 정함)

1. **`?panel` 단독의 dev 판정** — §11.7은 「?panel · ?analytics만 있으면 dev가 아니다」와 「필요한 상태가 없으면 고정 상태를 함께」를 같이 말한다. 캐릭터 상태가 필요한 패널(상점 · 인벤토리 · 스킬 · 사망 …)을 단독으로 주면 고정 상태(`PANEL_FIXTURE` — `src/app/query.js`)를 띄우고 그때만 dev로 한다(고정 상태 캐릭터가 실제 세이브 칸에 쓰이지 않게). 타이틀 · 설정 · 도움말 · 분석 같은 패널은 보통 세션 그대로. 모르는 쿼리 키는 dev로 바꾸지 않는다.
2. **개발용 캐릭터** — `?class` 단독은 `createCharacter`(시작 장비) · `?level` 또는 `?rift`가 있으면 `makeDevCharacter`. `?scene=town`이면 `?rift`가 있어도 마을에서 시작(해금만 n).
3. **장면이 바뀌면 패널을 닫는다** — app이 막 아래에서 `commitTravel` **직전에** `ui.closeAll('code')`(사망 · 완료 · 균열석 · 상점 패널이 새 장면에 남지 않게). commit이 낸 `HINT`의 안내 카드는 그 뒤에 열린다(P10은 `HINT`를 큐에 넣고 `update`에서 연다 · `SCENE_CHANGED`에서는 자기 `CLOSE_ON_SCENE`만 닫는다 — 결과가 같다). 막이 내려가는 동안 연 일시정지 · 분석 패널도 이때 닫힌다.
4. **막이 걷히는 중의 새 전환 요청**(부활 막 아래에서 미리 누른 「Enter — 복귀」) — 막을 다시 내리고 그 끝에서 commit한다. 막 없이 남은 `pendingTravel`은 다음 프레임에 막을 내린다(놓친 요청 · 멈춤 방지).
5. **봇과 포커스** — 봇이 켜져 있으면 창 포커스를 잃어도 일시정지 패널을 띄우지 않고 멈추지 않는다(§11.13 「사람이 연 일시정지 · 분석만 멈춘다」 — 관전 중 다른 창을 눌러도 돈다). 탭 숨김은 그대로 멈춘다. 봇이 켜져 있어도 멈추는 패널 = `BOT_HALT_PANELS`(pause · settings · help · confirm · analytics · 타이틀 계열).
6. **PAUSED reason** — `menu`(맨 위가 pause · settings · help) · `modal`(그 밖의 모달 — 상점 · 사망 · 완료 · 안내 …) · `blur` · `hidden` · `debug` · `context`. 전환 막 · 히트스톱 · 마을 패널은 일시정지가 아니다(PAUSED를 내지 않는다). `audio.setPaused`는 app이 탭 숨김에서만 직접 부른다.
7. **키 버퍼** — 모달이 먹은 「누르고 있는」 게임 키(스킬 숫자 · Shift)는 모달이 닫힌 뒤 눌림으로 남는다(에지 없이 — QUALITY §1). 겹쳐 보는 패널이 자기 `keys`로 먹은 키는 뗄 때까지 게임 입력이 아니다(스킬 창에서 Digit1을 누른 채 닫아도 스킬이 나가지 않게).
8. **디버그 API에 더한 것** — `__game.sim` · `__game.actions`(화면 확인 스크립트가 타이틀 · 새 캐릭터 · 타이틀로 · 부활을 ui와 같은 길로 밟는다). `step(n)`은 전환 막이 진행 중이면 그 틱만큼 막을 진행하고(실제 루프와 같게 그동안 sim은 step하지 않는다) 봇이 켜져 있으면 봇의 입력을 쓴다.

## 다른 패키지 · 통합 게이트가 볼 것(계약 문제)

- **[P10 · 통합] 문자열 키 없음** — §11.6 「세이브의 `v`가 미래 버전이면 덮어쓰지 않고 읽기 전용 안내」의 문면 키가 부록 B에 없다. app은 `STRINGS['notice.saveFuture']`가 있으면 그것을, 없으면 `notice.saveBlocked`를 지속 알림으로 쓴다. 권장: `'notice.saveFuture': '더 새 버전의 세이브다 — 읽기만 하고 저장하지 않는다'`를 `strings.ko.js`에 더한다(그러면 app이 바로 그것을 쓴다).
- **[P14] PAUSED{modal}** — 상점 · 사망 패널에서도 난다. AudioEngine이 PAUSED를 받아 AudioContext 전체를 멈추면 상점의 거래음 · UI음이 사라진다 — `modal` · `menu`에서는 지속음(환경 · 회오리)만 줄이는 쪽이 맞다. 탭 숨김은 app이 `setPaused(true)`를 직접 부른다.
- **[P8 · P13 · 리뷰] 지오메트리 수** — 같은 판(균열 1 → 완료 → 마을) 4번 반복에서 `memory().rc.geometries`가 141 → 153 → 156 → 158(DOM 251 · 리스너 45 · 텍스처 2는 그대로). app은 지오메트리를 만들지 않는다 — 풀이 처음 보는 외형마다 늘어나는 것인지 S6(§12.4)에서 더 긴 반복으로 본다.
- **[P2 · 참고] `debugGrant`는 SAVE_REQUEST를 내지 않는다** — 디버그로 준 골드 · 아이템은 다음 저장 시점(줍기 · 장면 전환 · 탭 숨김 · pagehide)에 같이 저장된다. 디버그 명령이라 그대로 두었다.

## 환경 관찰

- 이 클라우드 헤드리스 Chrome에서는 rAF가 균열 장면에서 약 1fps로 돈다(`setTimeout(50)`이 2초 걸린다) — `__game.step`의 한 번 렌더는 60ms 안. 화면 확인은 `pause` → `step`으로 하고 실제 시간 대기에 기대지 않는다.
