# NOTES-P11 — 갯바위(coast)

## 계약 · 남의 파일

- **프레임워크 파일은 한 줄도 고치지 않았다.** 데이터 두 파일(`data/stages/coast.js` · `data/species/coast.js`)은 §7.4.3 · §7.3.2 시드 그대로다(검산이 전부 통과해 조정할 것이 없었다).
- 계약 모순 · 남의 결함: 없음.
- P5 `src/view/world/placement.js`는 import 하지 않고 규칙을 베꼈다(NOTES-W1 §7).

## 내가 정한 것 (계약 밖 · 내부)

- **흘림 물길 비우기**: §9.4 의 「facing ± arc · 60m 시야」에 더해, 찌 · 봉돌이 흘러갈 수 있는 물(캐스팅 부채꼴에서 흐름 쪽으로 `CAST.driftArc` · `maxDriftM + 2m`)에는 바위 · 물보라를 두지 않는다 — 흘린 찌가 바위를 뚫고 지나가지 않게. 갯바위 세 자리의 흐름이 모두 +X 라 오른쪽(등대 쪽) 바다가 넓게 비고, 오른쪽 곶 줄기 · 등대 바위섬은 깊은 곶 자리에서 92m 너머에만 선다.
- 바위 판정 반경은 넉넉히(`FOOT_REACH` 1.6 × 반경 — 회전한 상자 기준). 걷는 영역 근처 바위 꼭대기는 땅 위 0.4m 이하.
- 등대 빛줄기 · 트럭 전구는 빛을 더하지 않고 emissive · 가산 혼합 메시다(빛 개수 고정).
- 이즈 오시마 실루엣(수평선 · `fog:false`)은 비에는 숨긴다.

## 사람이 확인할 것

- 거품 · 물보라의 실제 움직임(파도 주기로 번지고 사라짐) · 등대 빛줄기 회전 — 정지 화면으로만 봤다.
- 스폰에서 바다를 볼 때 걷는 영역(90 × 28m)이 넓은 검은 평지로 읽힌다 — 박힌 용암 덩어리 · 용암 줄기로 채웠지만 땅 색(P5 `look.terrain`)이 고르다. 더 거칠게 하려면 `COUNTS.*.slabs` 또는 P5 지형의 `rocky` 처리.
- 멀리 있는 물보라가 옅은 기둥처럼 보일 수 있다(`surgeMaterial` 의 spray 페이드 · `spray` 크기).
